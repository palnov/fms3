# Статус реализации проекта (Implementation Status)

Этот документ используется для отслеживания текущего состояния кодовой базы и реализованных фич. Перед тем как приступать к новой задаче, сверьтесь с этим списком.

## 1. Архитектура и Базовый Сетап
- [x] Инициализация Next.js (App Router), React 19.
- [x] Настройка Tailwind CSS v4.
- [x] Конфигурация MDX плагинов (`@next/mdx`, `@mdx-js/loader`).

## 2. API & Интеграции
### Партнерская сеть Правовед (Lead Generation)
- [x] **Backend API Route:** Создан `/api/leads` (принимает `name`, `phone`, `question`), проводит валидацию, добавляет `secret` из окружения и проксирует запрос в Feedot CPA.
- [x] **Конфигурация окружения:** `.env.local` и `.env.example` созданы с ключами `PRAVOVED_REFERRAL_ID` и `PRAVOVED_SECRET`.

## 3. UI/UX Системы сбора лидов (Lead Capture)
- [x] **Форма заявки (`LeadForm.tsx`):** Клиентский компонент формы с UI-валидацией 11-значного номера, лоадерами и визуализациями статусов.
- [x] **Глобальный виджет (`FloatingLawyerWidget.tsx`):** Липкая (fixed) кнопка "Задать вопрос", открывающая диалоговое окно юриста. Интегрирована глобально в `app/layout.tsx` (отображается на всех страницах).
- [x] **Компонент для статей (`ConsultationBanner.tsx`):** Динамический MDX-совместимый блок, использующий "Мягкий UX" (сначала предлагает нажать кнопку, затем разворачивает форму сбора контактов).

## 4. Глобальный Layout
- [x] Базовый скелет `RootLayout` и единая светлая тема; `dark:` активируется только явным классом `.dark`.
- [x] Внедрен глобальный заголовок `Header`.

## 5. AI и база знаний
- [x] RAG-консультант с мультиязычными ответами и ссылками на источники.
- [x] SQLite-индекс официальных документов и шаблонов.
- [x] Безопасный рендер ответов консультанта без вставки произвольного HTML.
- [x] Подписанный лимит запросов с обязательным `JWT_SECRET`.
- [x] Кэш embeddings с перезагрузкой при замене `knowledge.db`.
- [x] Redis rate limiting для AI, лидов и входа в админку.

## 6. Техническое SEO
- [x] Метаданные страниц и title template.
- [x] `robots.txt` и `sitemap.xml` через Next.js Metadata API.
- [x] Настоящий 404, error boundaries и Open Graph image.

## 7. Production и качество
- [x] Coolify-compatible standalone Docker image с non-root runtime и `/api/health`.
- [x] Persistent volume `/data` для базы знаний и журнала AI.
- [x] Privacy-страница, opt-out Яндекс Метрики и маскирование Webvisor.
- [x] Vitest, Playwright, GitHub Actions и Dependabot.
