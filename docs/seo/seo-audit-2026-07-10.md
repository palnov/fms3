# SEO-аудит ufms-help.ru

Дата аудита: 10 июля 2026 года

## Резюме

Техническая основа сайта рабочая, а главная страница и новые тематические URL уже присутствуют в поисковой выдаче. Главные ограничения роста — малая глубина большинства материалов, почти полное отсутствие внешних ссылок на первоисточники, слабая контекстная перелинковка, непоследовательные canonical для инструментов и отсутствие единой Article/Breadcrumb разметки.

Дополнительный риск связан со сменой версии сайта на существующем домене. В поиске остаются URL и фрагменты прежнего сайта, включая `/karta-sayta`. Их нужно либо сохранить как полезные страницы, либо перенаправить на наиболее близкий новый материал.

## Измеренные показатели

- 28 MDX-статей в текущем проекте.
- У всех MDX-страниц один H1.
- 25 из 28 материалов содержат менее 500 текстовых слов после исключения JSX-разметки.
- Только 2 материала содержат внешние ссылки; у большинства статей нет прямых ссылок на официальный источник.
- У многих дочерних материалов нет контекстных внутренних ссылок, кроме автоматически подобранного бокового блока.
- У статей заданы canonical URL, но у большинства страниц инструментов canonical отсутствуют.
- Sitemap не содержит `lastModified`.
- Общий Open Graph наследуется почти всеми страницами и не отражает заголовок конкретной статьи.
- Article и BreadcrumbList JSON-LD отсутствуют на статьях.
- Production fallback и часть документации указывали старый домен `fms3.ru` вместо `ufms-help.ru`.

## Приоритетные проблемы

| Приоритет | Проблема | Влияние | Решение |
|---|---|---|---|
| P0 | Неверный домен в fallback-настройках | Ошибочные absolute URL при неполной конфигурации окружения | Использовать `https://ufms-help.ru` во всех production defaults |
| P0 | Наследие старой версии домена | Потеря накопленных сигналов и поисковые 404 | Восстановить карту сайта, собрать старые URL из Webmaster/Search Console после подключения, настроить точечные 301 |
| P1 | Тонкие YMYL-материалы | Неполное соответствие намерению и слабые сигналы доверия | Расширить ключевые статьи конкретными сроками, суммами, документами, рисками и источниками |
| P1 | Нет официальных ссылок в большинстве статей | Слабая проверяемость юридических утверждений | Добавить ссылки на МВД, ФНС, pravo.gov.ru и действующие нормы |
| P1 | Нет Article/Breadcrumb JSON-LD | Поиску сложнее интерпретировать тип и место страницы | Добавить серверную JSON-LD-разметку по реестру статей |
| P1 | Пробелы в кластерах после получения статуса | Потеря long-tail запросов и переходов к консультации | Создать отдельные практические инструкции |
| P2 | Неполные canonical/OG у инструментов | Неоднозначные URL и слабые социальные сниппеты | Стандартизировать metadata |
| P2 | Нет `lastModified` в sitemap | Слабый сигнал обновления | Хранить проверенные даты изменения в реестре маршрутов |
| P2 | Автоматические связанные статьи не заменяют контекстные ссылки | Менее понятный путь пользователя | Добавить ссылки в шаги и итоговые блоки статей |

## Что уже сделано хорошо

- логичная кластерная структура URL;
- отдельные страницы под ВНЖ, РВП, гражданство и патент;
- корректный `lang="ru"`;
- robots закрывает API и админ-раздел;
- sitemap формируется из централизованного списка публичных маршрутов;
- у статей есть короткий ответ, FAQ, дата проверки и CTA;
- сайт явно сообщает, что не является государственным органом;
- мобильная навигация, горячая линия и ИИ-консультант поддерживают конверсию.

## Ограничения аудита

Данные Google Search Console и Яндекс Вебмастера отсутствуют. Поэтому текущие показы, клики, CTR, позиции и точная каннибализация по запросам пока неизвестны. Частотность и сложность ключей не выдумывались; приоритеты основаны на выдаче, намерении, полноте существующих страниц и ценности обращения.
