# Спецификация: Встраивание ИИ-чата прямо в статьи (ConsultationBanner)

## 1. Цель
Повысить вовлеченность пользователей и упростить UX: дать возможность общаться с ИИ-помощником непосредственно на странице статьи без перехода на отдельную страницу. Убрать неактуальные ссылки на сторонние сервисы проверки документов из баннеров.

## 2. Предлагаемые изменения

### 2.1 Изменения в `ConsultationBanner.tsx`
* Переводим баннер из режима простой ссылки-плашки в интерактивный компонент чата.
* **Сохранение контекста**: Текст заголовка (`title`) и описания (`description`) баннера остаются индивидуальными для каждой страницы (передаются через props из MDX, как и сейчас).
* **Удаление лишних кнопок**: Убираем кнопку «Проверить документ» / «Нужен специалист» (с кнопкой открытия формы обратной связи `LeadForm`).
* **Встроенный чат**:
  * Изначально под заголовком и описанием показывается поле ввода: `«Задайте вопрос по теме статьи...»` и кнопка `«Отправить»`.
  * При отправке первого сообщения баннер переходит в режим активного чата.
  * Внутри баннера появляется область с прокруткой сообщений.
  * История переписки и состояние отправки сохраняются локально в состоянии компонента.
  * Для форматирования ответов ИИ используется существующий компонент [SafeMessageText](file:///Users/Macbookpro/Documents/Developing/fms3/src/components/chat/SafeMessageText.tsx).
  * Запросы отправляются на существующий роут `/api/consultant` с передачей контекста текущей страницы в параметрах (чтобы ИИ понимал, какую статью читает пользователь).

### 2.2 Страница ИИ-консультанта (`/tools/ai-consultant`)
* Страница остается доступной по прямой ссылке.
* Ссылка на неё сохраняется в подвале сайта (`Footer.tsx`), но убирается из других баннеров, чтобы не дублировать функционал.

### 2.3 Очистка MDX-файлов от устаревших кнопок
* Проанализировать использование `secondaryHref` / `secondaryLabel` со значением «Проверить документ» и удалить их, оставив только контекстные ссылки (например, на калькуляторы), либо сделать так, чтобы `ConsultationBanner` игнорировал ссылки на внешние сервисы проверки документов.

## 3. Взаимодействие с API
* Чат будет отправлять `POST` запросы на `/api/consultant` с телом:
  ```json
  {
    "question": "текст вопроса",
    "language": "ru",
    "context": "Контекст страницы (например: Финальный CTA: депортация)"
  }
  ```

## 4. Верификация
1. Открыть любую статью (например, про проверку запрета на въезд `/legal/check-ban`).
2. Найти тёмный баннер «Следующий шаг».
3. Убедиться, что на нём нет кнопки «Проверить документ».
4. Ввести вопрос в поле ввода и нажать «Отправить».
5. Проверить, что ответ генерируется прямо внутри баннера и работает стриминг слов.
